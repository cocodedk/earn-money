# 8. Frontend pages

Create simple React pages.

No fancy design.

Use plain components.

Pages:

```text
Projects
Targets
Scan Runs
Scan Run Detail
Live Events
Findings
Evidence
```

Scan Run Detail must have buttons:

```text
Start
Pause
Resume
Stop
```

It must show:

```text
scan status
target statuses
live events
```

Use SSE for live events.

Reconnect on disconnect.
