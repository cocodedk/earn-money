# 15. MVP workflow and seed data

## MVP workflow

The GUI must support this path:

```text
Create project
Add three targets
Open stubs
Select 1.1 framework-detection
Create scan run
Start scan run
Watch live events
Pause scan
Resume scan
Stop scan, or let it finish
Open target result
Open findings
Open evidence
```
