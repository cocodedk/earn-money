# 14. Styling

## MVP styling

Keep it plain. Use:

```text
simple sidebar
simple top bar
tables
forms
status badges
small buttons
monospace blocks for JSON and raw excerpts
```

No charts. No animations. No complex design system.

## Status badge colours

Use simple visual states.

```text
queued = gray
running = blue
paused = yellow
stopping = orange
stopped = gray
failed = red
done = green
```

## Severity badge colours

```text
info = gray
low = blue
medium = yellow
high = orange
critical = red
```
