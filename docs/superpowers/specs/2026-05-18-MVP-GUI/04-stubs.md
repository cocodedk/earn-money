# 4. Stubs page

Route:

```text
/stubs
```

Purpose: show available scanner stubs.

Table columns:

```text
Phase
Spec
Slug
Title
Status
Fixture
Actions
```

For MVP, include one stub:

```text
1.1 framework-detection
```

Actions:

```text
View stub
Create scan run for this stub
```

Stub detail should show:

```text
Intent
Allowed actions
Fixture expectations
Pass/fail check
AI involvement
```

This can be read-only for MVP.
