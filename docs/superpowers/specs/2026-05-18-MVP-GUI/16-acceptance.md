# 16. Acceptance criteria

The GUI is accepted when:

```text
React app loads at http://localhost
sidebar navigation works
project can be created
target can be created
stub list shows 1.1 framework-detection
scan run can be created
start button calls backend
pause button calls backend
resume button calls backend
stop button calls backend
scan status updates
target status table updates
live events appear through SSE
findings list renders backend data
evidence list renders backend data
empty states are readable
errors are visible
```
