## Deferred follow-ups (tracked)

1. **Cross-run idempotence + dedup + `stale` flip** — depends on shared run-comparison infra not yet built. Same gap as 1.16/1.17.
2. **`is_documentation_like` false-positive guard** — mirror of `stack_traces.false_positives.is_documentation_like`; current MVP doesn't implement, so doc pages with SQL examples could false-positive. Spec §False-positive controls flags this.
3. **Echo-input regression test** — explicit test that a body containing only the probe sentinel produces no finding (it doesn't today because no signature matches the sentinel, but a regression-prevention test would harden this).
4. **WebGoat/DVWA integration fixture** — spec recommends primary; current MVP uses in-test mock only.
5. **POST-method support** — spec lists POST as conditional on prior phase marking the request shape safe; MVP defers.
6. **`_shared/secrets.py` lift** — 1.17 + 1.19 now both consume the same redaction pattern table. Cross-stub import works but should lift in a follow-up.
